========================================
Python 推导式 / 生成器 简单总结
========================================

【一句话总览】
列表、集合、字典 有"推导式"；
圆括号 ( ) 里的是"生成器表达式"，不是元组推导式；
Python 没有"元组推导式"。

----------------------------------------
1. 各种写法对照
----------------------------------------
[x for x in range(5)]          列表推导式   -> list
{x for x in range(5)}          集合推导式   -> set
{x: x for x in range(5)}       字典推导式   -> dict
(x for x in range(5))          生成器表达式 -> generator（不是元组！）
tuple(x for x in range(5))     元组的写法   -> tuple

----------------------------------------
2. 为什么 ( ) 不是元组推导式
----------------------------------------
因为圆括号另有用途，容易混淆：
(1)       只是数字 1，不是元组
(1,)      单元素元组
(x for x in range(5))   是生成器，不是元组
所以 Python 没有元组推导式，要元组请用 tuple(...)

----------------------------------------
3. 生成器 vs 列表/元组 的区别
----------------------------------------
特性            生成器表达式        列表/元组
求值时机        惰性（用时才算）    立即（一次算完）
能否重复遍历    否，只能遍历一次    可以多次
内存占用        很小（一次一个）    很大（全部存下）
能否索引 [0]    不能                能
能否 len()      不能                能

----------------------------------------
4. 生成器只能遍历一次（例子）
----------------------------------------
gen = (x for x in range(3))
print(list(gen))   # [0, 1, 2]
print(list(gen))   # []   第二次就空了！

----------------------------------------
5. 想要元组怎么办
----------------------------------------
tup = tuple(x for x in range(5))       # 方式一
tup = tuple([x for x in range(5)])     # 方式二

----------------------------------------
6. 记忆口诀
----------------------------------------
方括号 [ ] = 列表
花括号 { } = 集合或字典
圆括号 ( ) = 生成器（惰性、一次性、省内存）
要元组     = tuple(...)
没有元组推导式！
